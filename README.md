# VueLotteryApp

Веб-застосунок для лотереї, розроблений з використанням Vue 3, Vite та TypeScript. Проєкт включає систему автентифікації, управління користувачами та компоненти для відображення переможців. Проєкт побудовано за методологією Feature-Sliced Design (FSD).

## Основний функціонал
* **Автентифікація:** Вхід до системи та управління сесіями.
* **Управління користувачами:** Перегляд списку користувачів, їх деталей та редагування профілів.
* **Відображення результатів:** Спеціальні UI-компоненти для показу переможців.
* **API Інтеграція:** Налаштований HTTP-клієнт для взаємодії з бекендом.
* **Управління станом:** Глобальні сховища Pinia для даних користувачів та авторизації.

## Технологічний стек
* Фреймворк: **Vue 3 (Composition API)**
* Збирач: **Vite**
* Мова: **TypeScript**
* Маршрутизація: **Vue Router**
* Стейт-менеджер: **Pinia**
* UI-бібліотека: **PrimeVue**
* Валідація: **VeeValidate + Zod**
* Стилізація: **SCSS**

## Архітектура (Feature-Sliced Design)

Проєкт використовує архітектурну методологію FSD. Код поділено на шари з суворою ієрархією залежностей (модулі можуть імпортувати лише з шарів, що знаходяться нижче).

## Структура директорій (src/)
* app/ — глобальні налаштування, ініціалізація застосунку, реєстрація сервісів, маршрутизація, глобальні стилі.
* pages/ — компоненти сторінок (наприклад, Home, Users, Login, NotFound).
* widgets/ — складні самодостатні блоки (наприклад, AppHeader, UsersTable).
* features/ — бізнес-дії користувача (auth, user-form).
* entities/ — бізнес-сутності предметної області (user, session, theme), їх моделі (Store) та API-сервіси.
* shared/ — спільний код без прив'язки до бізнес-логіки (обгортки UI-компонентів, базовий HTTP-клієнт, ServiceProvider).
