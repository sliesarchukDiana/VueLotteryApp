# VueLotteryApp

Веб-застосунок для лотереї, розроблений з використанням Vue 3, Vite та TypeScript. Проєкт включає систему автентифікації, управління користувачами та компоненти для відображення переможців.

## Основний функціонал
* **Автентифікація:** Вхід до системи та управління сесіями (реалізовано через `LoginView` та `auth.service.ts`).
* **Управління користувачами:** Перегляд списку користувачів, їх деталей та редагування профілів (`UsersView`, `UserDetailsView`, `UserEditView`).
* **Відображення результатів:** Спеціальні UI-компоненти для показу переможців (`WinnerBadge`, `WinnerBlock`).
* **API Інтеграція:** Налаштований HTTP-клієнт для взаємодії з бекендом (`http-client.ts`).
* **Управління станом:** Глобальні сховища для даних користувачів та авторизації (директорія `stores`).

## Технологічний стек
* Фреймворк: **Vue 3**
* Збирач: **Vite**
* Мова програмування: **TypeScript**
* Маршрутизація: **Vue Router**
* Стилізація: **SCSS**
* Контроль якості коду: **ESLint** (`.eslintrc.cjs`)

## Структура директорій
* `src/api/` — конфігурація HTTP-клієнта.
* `src/components/` — базові та специфічні UI-компоненти (кнопки, поля вводу, модальні вікна).
* `src/app/layouts` — макети сторінок (авторизація, стандартний макет, макет користувачів).
* `src/app/providers/router` — конфігурація маршрутів.
* `src/services/` — сервіси для бізнес-логіки та роботи з даними.
* `src/stores/` — модулі управління станом застосунку.
* `src/views/` — основні сторінки (Home, About, Login, Users, NotFound тощо).
